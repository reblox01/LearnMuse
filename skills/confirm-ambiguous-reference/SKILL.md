# Confirm ambiguous reference

Use when the user points at something with "this", "that", "abt this message", or a bare pronoun, and more than one thread, message, or item could fit.

## Rule

- Do not guess which item the user means. Ask which one, naming the candidates, before you act on it or summarise it.
- A guess that turns out wrong costs a correction and a wasted summary; a one-line question costs nothing.
- Once the user confirms the item, act on that item only. Do not carry over work from the item you first guessed.

## Do not capture

- A reference with only one possible fit is not ambiguous: act on it.
- A fact about which item the user picked belongs in memory, not here.
